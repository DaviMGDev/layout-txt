## Reasoning chains
- Filename order mirrors label-first philosophy: screen name first ([label](type) = label first; login.layout.txt = screen first, kind after). Prefix form LAYOUT.login.txt groups layouts in listings but buries the screen name.
- Scale determines organization: 1 screen → LAYOUT.txt; few → flat *.layout.txt; many/feature-scale → folder per page with uniform LAYOUT.txt (folder = screen name). Both forms satisfy invariants: one file per screen, screen name recoverable, glob-able (*.layout.txt or **/LAYOUT.txt), no index file.
- Duplication of shared blocks per page is acceptable at wireframe level: each file self-contained and independently verifiable; notes point to source of truth; imports were explicitly rejected (ceremony).

## Key insights
- The filesystem is the index — glob replaces any registry/index file.
- Screen inventory for agents = glob `*.layout.txt` / `**/LAYOUT.txt`.
