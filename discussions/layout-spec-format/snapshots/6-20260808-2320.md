### Decisions
- Format: LAYOUT.txt — plain text, own grammar, no markdown semantics, no fences, UTF-8 (LOCKED)
- Syntax family: label-first [Label](type:variant attrs) — kept after full comparison (LOCKED)
- Line kinds (disjoint by first char): '#' = NOTE; '[' or '(' = WIDGET; anything else = TEXT (text widget, label = trimmed line) (LOCKED)
- Leaf: [LABEL](TYPE[:VARIANT] ATTRS); label = up to first ']'; type = first token; variant = after first ':'; attrs = opaque, never parsed/verified, must not contain ')' (LOCKED)
- Container: (TYPE[:VARIANT] ATTRS) with indented children = group; without = label-less leaf; no depth limit (LOCKED)
- Hierarchy: parent = most recent preceding widget line with strictly smaller indent; children = following lines with greater indent (LOCKED)
- Rows: same line = row (layout hint only, never verified); new line = stacked; (row)/(column)/(grid) = convention types (LOCKED)
- Repetition: xN suffix on any item (repeats immediately preceding item; group = whole subtree; x0 = parse error; x1 = legal no-op) (LOCKED)
- Notes: '#' prefix; attach to the following widget line; top-of-file notes = screen meta; never verified (LOCKED)
- Static text: bare lines = text widgets (headings/captions verified by label) (LOCKED)
- Files: one screen per file, <screen>.layout.txt; single-screen projects may use LAYOUT.txt; no index/imports; filename = screen name (LOCKED)
- Vocabulary: free-form; unknown types = INFO only; variants/attrs symmetric for containers (LOCKED)
- Links: 'link' is a convention type, target = opaque attr; no first-class treatment (LOCKED)
- Verification: parse errors = ERROR; structural subsequence match (type/variant/label/order/counts) over the agent-extracted app tree; unmatched app nodes & unknowns = INFO; duplicates/unverifiable variants = WARNING; FAIL iff any ERROR; exit 0/1/2; ~few hundred lines, no deps (LOCKED)
- Edge cases: ']' in labels forbidden (use a note); trailing whitespace ignored; tabs in indent = parse error; non-ASCII labels OK; attrs with ')' inexpressible; malformed widget lines = file parse error; prose starting with '(' = unknown-type leaf INFO; x0 error; x1 legal (LOCKED)
- Naming: LAYOUT.txt (pairs with DESIGN.md); per-screen <screen>.layout.txt (LOCKED)
