### Locked decisions (full)
- Format: LAYOUT.txt — plain text, own grammar, no markdown semantics, no fences, UTF-8.
- Syntax family: label-first [Label](type:variant attrs) — kept after full comparison vs type-first, md-headings, box-drawing, fenced type-first, Fountain-lenient. Winner on read-speed, determinism, txt-fit.
- Line kinds (disjoint by first char): '#' = NOTE; '[' or '(' = WIDGET; anything else = TEXT (text widget, label = line).
- Leaf: [LABEL](TYPE[:VARIANT] ATTRS); label = up to first ']'; type = first token; variant = after first ':'; attrs = opaque, never parsed/verified, must not contain ')'.
- Container: (TYPE[:VARIANT] ATTRS) with indented children = group; without = label-less leaf (empty group = label-less leaf). No depth limit.
- Hierarchy: parent = most recent preceding widget line with strictly smaller indent; children = following lines with greater indent; multi-item row children attach to LAST item.
- Rows: same line = row (layout hint only, never verified); new line = stacked; (row)/(column)/(grid) = convention types.
- Repetition: xN SUFFIX on any item (repeats immediately preceding item; group = whole subtree; x0 = parse error; x1 = no-op).
- Notes: attach to following widget line; top-of-file notes = screen meta; note indent irrelevant; never verified.
- Static text: bare lines = text widgets (headings/captions verified by label).
- Files: one screen per file, <screen>.layout.txt; single-screen projects may use LAYOUT.txt; no index/imports; filename = screen name.
- Vocabulary: free-form, unknown types = INFO only. Variants/attrs symmetric for containers.
- Links: 'link' is convention type, target = opaque attr; no first-class treatment.
- Verification: parse errors = ERROR; structural subsequence match (type/variant/label/order/counts) over agent-extracted app tree; unmatched app nodes & unknowns = INFO; duplicates/unverifiable variants = WARNING; FAIL iff any ERROR; exit 0/1/2. ~few hundred lines, no deps.
- Edge cases: ']' in labels forbidden (use note); '(' in labels OK; trailing whitespace ignored; tabs in indent = parse error; non-ASCII labels OK; attrs with ')' inexpressible; malformed widget lines = file parse error; prose starting with '(' = unknown-type leaf INFO; x0 error; x1 legal.
- Naming: LAYOUT.txt (pairs with DESIGN.md); per-screen <screen>.layout.txt.
