# attrs-passthrough — opaque parameters for the implementer (G3)
# ATTRS = everything after the type token up to the closing ). Verbatim,
# never parsed, never verified. URLs, placeholders, data — anything.

# Rules: no `)` inside attrs (the first ) closes the widget); anything
# inexpressible goes into a # note instead.
